Open source, private by default

KinShip is built and maintained in the open. Here is what you can rely on: the license, the security policy, what the app contacts, and how to take part.

License

KinShip is free software under the GNU AGPL-3.0-or-later. You may run it, change it and share it. If you run a modified copy as a service for other people, you must offer those people the source of your changes.

That is why every running instance has an About KinShip page showing its version and a link to this repository.

Security

Please report vulnerabilities privately, through GitHub's private security advisories on the repository, and not in a public issue.

Only the newest release is supported, so the answer to many reports is a patch release and a request to upgrade. Security releases are marked in red in the app's update notice.

Report a vulnerability

What the app contacts

Once a day KinShip can read GitHub's public release list to tell your SuperAdmin about new versions. It sends nothing about your installation: no version, no instance name, no user count.

It is a single toggle in Admin, off with one click, and the app works fully without internet.

  • AI features are optional and off by default. Nothing in the app calls an AI service unless an admin connects one.
  • No update emails.
  • Files are encrypted before they are stored.
  • This website loads no fonts, scripts or trackers from anyone else.

Name and logo

The code is AGPL, but the KinShip name and logo are not. If you publish a fork, please give it another name and logo. The details are in TRADEMARK.md.

Contribute

Small pull requests with tests are the easiest to review. Commits follow Conventional Commits and carry a sign-off, and contributions are accepted under the same license.

  • Issues for bugs and for work left out of a release
  • Discussions for questions and ideas
  • Translations are welcome once 1.0 lands, with a guide for new languages
