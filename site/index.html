Your family's history, on your own server.

KinShip is a self-hosted family tree you run with one Docker Compose file. Relatives, photos and stories stay on your server, and family health history stays private unless a person chooses to share it.

Get started View on GitHub

An illustration of sample data: the Darwin–Wedgwood family, from public historical records. Pedigree, Fan and Descendants are previews of the charts arriving in 0.3.

Built around three promises

It is yours

Three containers on your hardware. Nothing about your family is sent anywhere. AI features are optional and stay off until an admin connects one. The only other outbound request is an optional daily look at GitHub's public release list.

Private by design

Medical history is private by default and shared person by person, enforced by the database itself. Uploaded files are encrypted before they are stored.

Safe to upgrade

Migrations only move forward and keep your data. Built-in encrypted backups, an automatic safety copy before every database change, and every upgrade path tested before release.

Running in a few minutes

  1. 1Download compose.yml and the example settings file.
  2. 2Set a database password and a file encryption key in .env.
  3. 3Start it, then open the site and follow the first-run setup.
Read the install guide 
# download the release files
curl -LO https://github.com/officialJCReyes/kinship/releases/latest/download/compose.yml
curl -LO https://github.com/officialJCReyes/kinship/releases/latest/download/env.example
cp env.example .env

# start web, api and db
docker compose up -d
